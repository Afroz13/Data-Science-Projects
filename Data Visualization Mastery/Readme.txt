# Interactive Sales Dashboard 📊

An Interactive Sales Dashboard project developed using **Python, Pandas, Seaborn, Matplotlib, and Plotly** to analyze sales performance, product trends, regional insights, and customer purchasing behavior through statistical and interactive visualizations.

---

# 📌 Project Overview

This project focuses on transforming raw sales transaction data into meaningful business insights using data analytics and visualization techniques.

The dashboard combines:

* Statistical analysis
* Business intelligence reporting
* Interactive visualizations
* Professional dashboard design

The project was developed in **Google Colab** and includes both static and interactive dashboards.

---

# 🎯 Project Objectives

* Analyze sales trends over time
* Compare product-wise sales performance
* Understand regional sales distribution
* Explore relationships between quantity and revenue
* Create statistical visualizations
* Build interactive business dashboards
* Present insights in a professional reporting format
