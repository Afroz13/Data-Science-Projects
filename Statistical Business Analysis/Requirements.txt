Requirements:
	1. Python >= 3.9 — runtime for scripts and notebook.
	2. pandas == 2.1.* — data loading, cleaning, aggregation.
	3. numpy == 1.26.* — numerical operations and arrays.
	4. matplotlib == 3.8.* — static plotting and figure export.
	5. seaborn == 0.12.* — enhanced statistical visualizations.
	6. scipy == 1.11.* — statistical tests (Shapiro, t-tests, ANOVA).
	7. scikit-learn == 1.3.* — LinearRegression and metrics.

	8. jupyterlab or notebook >= 3.0 — run and view the Colab/notebook locally (optional if using Colab).
	9. ipykernel — required for Jupyter execution environments.
	10. git — version control.

Use pip install -r requirements.txt to install.
